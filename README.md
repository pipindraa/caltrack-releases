# CalTrack — сборки

Публичный репозиторий релизов приложения CalTrack. Исходный код хранится отдельно.

## Установка

1. Скачайте APK из раздела [Releases](../../releases).
2. Откройте файл на устройстве и разрешите установку из неизвестных источников.
3. Дальнейшие обновления приложение проверяет и скачивает отсюда автоматически.
